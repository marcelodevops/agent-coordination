## Goal

## Why this is format-safe

A JSON string literal (`ensure_ascii=False`) escapes `"`→`\"`, `\`→`\\`, control chars (`\n` etc.), and leaves non-ASCII raw — which is simultaneously a valid TOML basic string and a valid YAML double-quoted scalar. One encoded token therefore covers all three targets without a bespoke escaping framework. Values are inserted in a single `safe_substitute` pass, so a `$`-bearing description is treated as data, not re-scanned as a directive.
