## Findings addressed

The coordinator showed that round 1 normalized destinations **lexically** (`PurePosixPath`), which cannot collapse `..` and cannot see in-root symlink aliases, so two cases still silently overwrote in a real `_write_local` call:

1. New target — `{README.md: first, dir/../README.md: second}` → final `README.md` became `second`.
2. Existing target `--force` with `alias -> real` symlink — `{real/file.txt: first, alias/file.txt: second}` → final `real/file.txt` became `second`.

## Fix

`bootstrapper/cli.py`:

- New `_reject_resolved_collisions(planned, root)` runs on the **resolved** destinations produced by `_safe_join` (`Path.resolve()` collapses `..` and follows symlinks), **before** the first `mkdir`/`write_text`. It raises `PathCollisionError` when two entries resolve to the same destination with different content, and when a resolved file is also the parent directory of another resolved file.
- `_write_local` now: keeps the lexical `find_output_conflicts(files)` (composition/rendered contract) **and** the `_safe_join` containment/outside-target guard, then builds the resolved plan, then runs `_reject_resolved_collisions`. Write loop is unchanged apart from consuming the resolved plan.

`bootstrapper/composer.py`: unchanged this round (round-1 lexical/rendered checks retained). No signatures changed; the outside-target symlink guard was **not** removed.

`tests/test_output_path_contract.py`: added 3 regression tests for the two reported gaps plus a resolved file-over-directory-via-`..` case.

## Verification commands and results

- `/tmp/projboot-execution-venv/bin/python -m pytest -q` → **75 passed** (baseline 60 + 15 contract tests; +3 this round; no regressions).
- Direct `_write_local` reproduction of both reported scenarios against the fixed code:
  - `dir/../README.md` vs `README.md` → **rejected (Exit)**, target dir never created.
  - symlink `alias -> real`, `alias/file.txt` vs `real/file.txt` (`--force`) → **rejected (Exit)**; `real/file.txt` left **absent** (never overwritten).
  - Each prints a clear message: `'...' and '...' resolve to the same output '...' through a '..' traversal or a symlink; refusing to overwrite one with the other`.
- Round-1 CLI cases still reject: `create ... --prompts-file ./README.md` and `--prompts-file src` (exit != 0, no project dir).
