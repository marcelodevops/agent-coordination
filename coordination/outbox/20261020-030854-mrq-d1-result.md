## What was implemented

A new `preview` CLI command that shows the fully composed project layout, selected
tools/integrations, and requested post-generation actions for the same arguments
`create` accepts — with zero side effects.

### `bootstrapper/cli.py` (only production file changed)

1. **Shared composition path** — extracted `_resolve_options_and_compose()`:
   `create` and `preview` both call it, so the previewed file dict is the identical
   resolved-preset + `compose_project_files()` result that generation writes. No
   behavior change to `create` (its inline try/except → `BadParameter` mapping moved
   into the helper verbatim).
2. **Shared read-only preflight** — extracted `_validate_write_plan()` from the top
   half of `_write_local()`: non-empty-target refusal (exit 1), `find_output_conflicts`,
   `_safe_join`, `_reject_resolved_collisions`, not-a-directory target, and
   `_reject_existing_fs_conflicts` (forced merge). It only reads filesystem state
   (`resolve`/`exists`/`iterdir`); `preview` calls it so invalid inputs and output
   collisions fail exactly where `create` would fail, before any output claim.
   `_write_local()` keeps identical messages/exit codes and now reuses this helper
   plus `_is_nonempty_dir()`.
3. **`preview` command** — mirrors `create`'s options (`--lang`, `--agent`, `--preset`,
   `--arch`, `--outputs-dir`, `--scripts-dir`, `--prompts-file`, `--remote`, `--create`,
   `--clone`, `--description`, `--private`, `--org`, `--license`, `--holder`, `--var`,
   `--no-git`, `--no-graphify`, `--force`) and validation order (`_validate_name`,
   `_reject_contradictory_options`, remote whitelist). It never calls `_write_local`,
   `_push_github`, `run_post_hooks`, or any subprocess.
4. **Honest output** (`_echo_preview`) — sections: composed totals (files + bytes,
   in memory), `Files that \`create\` would write`, `Directories implied by that
   layout`, `Selected tools and integrations` (base template, preset/arch/dirs/prompts,
   agents, license, graphify scaffolding, `.remember/` memory, `.agents/skills/` —
   derived from the composed files, not from flags), and `Post-generation actions`
   where every selected action is marked "not executed by preview" and every external
   requirement (graphify CLI on PATH, GitHub credentials + network) is marked
   "NOT CHECKED by preview". Deselected actions show "not selected (--flag)". A
   closing line states selected/required lines are descriptions, not verifications.

## Limitations / decisions for the reviewer

- Preview covers the `create` flow only (the assignment's "same inputs as generation"
  is the `create` pipeline); `init`/`init-from-tree` previews were not added as the
  plan's Delivery D scopes preview to the bootstrap creation experience.
- `preview --force` into an existing tree still runs the on-disk conflict check and
  can fail — this mirrors `create`, which is the required "output collisions fail
  before side effects" behavior.
- Preview inherits `create`'s informational echo for unknown-but-skippable cases
  (e.g. `license: none (no LICENSE composed)`), keeping honesty over flag mirroring.
- No README changes were made (out of ownership); surfacing `preview` in user docs
  belongs to a docs-labeled task.
