## Finding 1 (blocking) — `$` accepted a trailing newline. Fixed.

`_NAME_RE` ended in `$`, which also matches the position **before a terminal
newline**, so `_validate_name("demo\n")` returned normally and the scaffold was
written into a newline-named directory. Validation is now a complete-string check:

- `$` → `\Z` (only matches at true end of string)
- `.match()` → `.fullmatch()` (also refuses acceptance on a prefix match)

Changed in `bootstrapper/cli.py` only (ownership preserved).

Reproduced before the fix — `create "demo\n" ... --create` exited **0** and left a
real directory behind:
`work/demo\n` appeared in the working dir
(`assert {PosixPath('.../work/demo\n')} == set()`).

After the fix, direct verification at the reviewer's own entry point
(`bootstrapper.cli._validate_name`):
