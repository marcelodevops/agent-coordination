## Goal

Reject two classes of output collision **before anything is written**:

1. **Aliases of the same destination** — e.g. `--prompts-file ./README.md` normalizes onto the template's `README.md` and silently overwrote it.
2. **File/ancestor conflicts** — e.g. `--prompts-file src` produces a rendered file `src` while the Python template also renders `src/main.py`; the write crashed half-way (`IsADirectoryError`) leaving a partial project.

## Changed files (within ownership only)

- `bootstrapper/composer.py` — new `find_output_conflicts(files)`; collision-aware rendered-path building (a raw path that renders onto an existing destination with different content now raises instead of being dropped by the dict literal); `compose_project_files` calls the conflict check on the final plan.
- `bootstrapper/cli.py` — `_write_local` now runs `find_output_conflicts(files)` inside its existing up-front validation, before the `_safe_join` path plan and before any `mkdir`/`write_text`.
- `tests/test_output_path_contract.py` — NEW (12 tests).

`compose_project_files`, `_write_local`, `PathCollisionError` and the `_safe_join` containment/symlink guard keep their existing signatures and behavior; the preflight is added on top.

## Reproduction → fix (before/after)

Reproduced against the unfixed checkout via `CliRunner`:

- `create proj -l python --prompts-file ./README.md` → **before**: exit 0, `README.md` content became the prompts catalog (silent clobber). **after**: exit 2, project dir never created (0 files).
- `create proj -l python --prompts-file src` → **before**: exit 1 with `IsADirectoryError`, partial files written. **after**: exit 2, project dir never created (0 files).
